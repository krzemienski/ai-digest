## Important Rules

1. **Sequential execution**: Tasks MUST be done in order (dependencies exist)
2. **No skipping**: Every task must pass verification before advancing
3. **Real validation**: Use actual commands, not assumptions
4. **Commit discipline**: Each task with a Commit message gets its own git commit
5. **Evidence-based**: Capture and verify evidence for every claim
6. **Recovery**: If stuck on a task for 3+ iterations, log the blocker and ask for help
